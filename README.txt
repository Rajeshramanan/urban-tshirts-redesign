# URBAN T-SHIRTS — Website Version 3

A professional, Myntra/Meesho-inspired front-end storefront for URBAN T-SHIRTS.

## Included
- Modern responsive storefront
- Search and category filters
- Product cards with sizes
- Shopping bag/cart
- 3-piece combo at ₹499
- WhatsApp checkout
- Product Manager page (`admin.html`)
- User-supplied product/brand images
- Mobile-friendly layout

## Run it
Open `index.html` in a browser.

## Add/update products
1. Put the new product photo into `assets/`.
2. Open `admin.html`.
3. Enter the photo path, e.g. `assets/new-tee.jpg`.
4. Fill in name, price, category and sizes.
5. Click Save product.

## Important
The admin page uses browser localStorage. This means product changes are stored only on the same browser/device. It is ideal for a prototype or local store demo.

For a real public online store, the next upgrade should connect the product manager to a database/backend so you can update products from any phone or computer.
